# Security Policy

If you believe you've found a security vulnerability in `@stedi/sdk` or `stedi`, **don't open a public issue**. Email **security@stedi.com** with:

- A description of the vulnerability.
- Steps to reproduce.
- Affected versions.
- Any proof-of-concept you have.

We'll acknowledge within two business days and follow up with an estimated remediation timeline. Coordinated disclosure terms negotiable case-by-case.

## Supported versions

Pre-1.0 (`0.x`) releases receive security fixes on the latest published minor only. Post-1.0 support policy will be published with the v1.0 release notes.
