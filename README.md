# Stedi SDK

Unified, typed access to Stedi's APIs from a single client, for TypeScript and Python.

This repository is the public release mirror of those two packages, generated from Stedi's
build pipeline: each release tag holds the package source and examples for the version
published to npm and PyPI.

## Install

```sh
npm install @stedi/sdk
```

```sh
pip install stedi   # or: uv add stedi
```

Each package's README has a quickstart; [`examples/`](./examples) has a runnable sample for
every operation, in both languages. The full API reference lives at
[docs.stedi.com](https://docs.stedi.com).

## Building from source

**TypeScript** (`packages/typescript`) ships prebuilt `dist-cjs`, `dist-es` and `dist-types`, so
building is only needed to verify them or to work from a modified checkout:

```sh
cd packages/typescript
npm install
npm run build
```

**Python** (`packages/python`) ships source only — build it to get an installable wheel or sdist:

```sh
cd packages/python
uv build
```

See each package's README for prerequisites.
